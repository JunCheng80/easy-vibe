# Stage 0｜课程信息输入（请按勾选/填空完成）

## 1. 基础信息
- 课程名称：``
- 授课对象（年级/专业）：``
- 总学时：``（例如 32/64）
- 授课周期：``（例如 8 周 / 16 周）
- 教材/资料：``

## 2. 本课程的“产出物”你要哪些？（勾选）
- [ ] 课时/章节安排表（Stage-1）
- [ ] 每章“重难点+案例+课堂活动”（Stage-2）
- [ ] 作业/实验清单与评分标准（Stage-3）
- [ ] 期末复习提纲（Stage-3）
- [ ] PPT 页级大纲（可选）

## 3. 风格与约束（决定生成质量）
- 语言风格：`简洁 / 讲故事 / 比较学术 / 偏口播`
- 课程特色关键词（3-8 个）：``
- 必讲章节/必须覆盖知识点：``
- 学生基础情况（弱/一般/强）：``
- 禁止内容或雷区（例如：不要太长、不要太理论）：``

## 4. 你希望“备课生成器”的输出格式
- 输出格式：`Markdown / Word结构 / PPT结构`
- 每个课时的结构模板（默认也行）：
  - 目标 → 重难点 → 讲解 → 例题/案例 → 互动 → 作业
