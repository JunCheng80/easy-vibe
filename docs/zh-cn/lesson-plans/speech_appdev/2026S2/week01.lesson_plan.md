# 课程教案｜Week 1｜课程导入 + 声学基础 + Praat入门

## 教学目标
- 说清声音的产生与传播、声波的基本描述方式
- 理解常见声音客观衡量指标与主观属性
- 完成Praat安装与基础操作（打开/查看波形与频谱）

## 教学重点
- 声波描述：时域与频域的直观理解
- Praat的基本界面与核心操作

## 教学过程（建议）
### 讲授（60分钟）
- 课程说明：考核/作业/项目
- 声学基础：声音产生传播、声波描述、客观衡量与主观属性
### 演示（30分钟）
- Praat安装与打开音频
- 查看波形/频谱/语谱图入口

## 课后作业
- 完成Praat安装；上传1段自录语音（3~5秒）并截图展示波形
- 用100~200字解释：你录制语音的能量变化与发声过程的关系
